##  Dataset Details (R Project)
**Dataset Name:** AirPassengers  
**Source:** Built-in R dataset  
**Description:**  
The AirPassengers dataset contains monthly totals of international airline passengers from 1949 to 1960. It is a time-series dataset commonly used for trend and seasonality analysis.
